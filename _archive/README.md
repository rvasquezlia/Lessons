# _archive

These folders contain the original day-by-day Q01W01/Q01W02 lesson pages that pre-date the Topics-based structure.

They were retired in August 2026 when the curriculum was reorganised so that each topic lives under  
`Lessons/{Grade}/Topics/{topic-slug}/` with reusable, date-independent page types  
(vocabulary, explanation, guided, exercises, enrichment, assessment, teacher-guide).

Do **not** link to these pages from new content. They are kept here only to preserve any  
bookmarked or printed references that used the original paths.
