Concrete Scenario: Equation Classification Challenge
A false statement like \(6 = 7\) means no solution. A true statement like \(4 = 4\) means infinitely many solutions. Anything else simplifies to exactly one solution.
What to do on this tab With your group, predict each equation's classification first, then solve to verify. Select a classification, and if it has one solution, also enter the value of x.
Real-Life Application: Comparison Scenario
What to do on this tab Set up an equation for each situation, classify it, and explain what the classification means in context.

Two Savings Plans

Friend 1 starts with \(\$50\) and saves \(\$10\) per week: total after \(x\) weeks is \(50 + 10x\). Friend 2 starts with \(\$80\) and also saves \(\$10\) per week: total after \(x\) weeks is \(80 + 10x\).

Task: set \(50 + 10x = 80 + 10x\) and classify it. What does that classification mean for these two friends' savings?

Two Ways to Write the Same Plan

A phone plan's monthly cost is written two different ways by two different billing systems: \(2(3x + 5)\) and \(6x + 10\), where \(x\) is gigabytes of extra data used.

Task: set \(2(3x+5) = 6x+10\) and classify it. What does that classification mean about the two billing systems?
