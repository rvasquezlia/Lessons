Warm-Up: Properties of Equality & Inverse Operations

Monday, August 17, 2026 · 90 min (Double Period) · HSA.REI.A.1, HSA.REI.B.3 & MP.7: Look for and Make Use of Structure

Every equation you solve today rests on one idea: whatever you do to one side of an equation, you must do to the other side, or the equation stops being true. Before we work with multi-step equations, confirm you can name the property behind each move.
Properties of Equality
  • Addition Property: if \(a = b\), then \(a + c = b + c\).
  • Subtraction Property: if \(a = b\), then \(a - c = b - c\).
  • Multiplication Property: if \(a = b\), then \(ac = bc\).
  • Division Property: if \(a = b\) and \(c \neq 0\), then \(\frac{a}{c} = \frac{b}{c}\).

Lesson 1-2: Solving Linear Equations
A linear equation with the variable on one side can always be solved by undoing operations in reverse order (reverse PEMDAS): simplify each side first, then use inverse operations to isolate the variable.

When the Variable Disappears

Sometimes collecting variable terms eliminates the variable entirely. What's left tells you the answer:

\(2(x+3) = 2x + 7 \;\rightarrow\; 2x + 6 = 2x + 7 \;\rightarrow\; 6 = 7\). A false statement means no solution - no value of \(x\) works.

\(4(x+1) = 4x + 4 \;\rightarrow\; 4x + 4 = 4x + 4 \;\rightarrow\; 4 = 4\). A true statement means infinitely many solutions - every value of \(x\) works.
