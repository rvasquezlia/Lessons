Solving for a Variable That Appears Once
Type only the expression for the target variable - not "x =", just what goes on the other side. For a fraction, use a slash: type d/t for \(\dfrac{d}{t}\).
Before You Start: The Question Ladder
#Question
1What's the variable I need to isolate?
2What is obstructing me from doing so?
3What is it doing?
4What's the inverse operation to remove it? Apply it to both sides.

Every item on this tab needs exactly one trip through these four questions. See the Explanation page or the Guided Solving Ladder for fully worked examples.

Multi-Step Literal Equations
These need an addition or subtraction step before you divide. Use parentheses in your answer wherever the whole numerator (or denominator) needs to be grouped, e.g. (P-2w)/2.
Climb the Question Ladder Twice

Ask the same four questions from Tab 1 - variable? obstruction? operation? inverse? - to clear the first obstruction. Then ask them again on whatever is left obstructing the variable now.

Distributing & Factoring
In each of these, the target variable appears more than once. Factor it out before you divide.
The Extra Question for This Tab

Variable in more than one term? Factor it out first - then finish with the Question Ladder from Tab 1.
