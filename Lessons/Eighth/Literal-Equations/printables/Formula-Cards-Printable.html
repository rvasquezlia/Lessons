Literal Equations · Practice Set

Formula Rearrangement Cards

For the teacher Print and hand out to small groups or pairs for a paper-first rearranging round before students transfer answers to the Practice Set page. Answer key is in the Teacher's Guide.

Tip: in the print dialog, set Margins to "Default" and turn off "Headers and footers" for the cleanest printout.

One Appearance

1. \(d = rt\), solve for \(r\).

2. \(d = rt\), solve for \(t\).

3. \(A = lw\), solve for \(l\).

4. \(A = lw\), solve for \(w\).

5. \(I = Prt\), solve for \(P\).

6. \(I = Prt\), solve for \(t\).

Multi-Step

7. \(P = 2l + 2w\), solve for \(l\).

8. \(P = 2l + 2w\), solve for \(w\).

9. \(F = \dfrac{9}{5}C + 32\), solve for \(C\).

10. \(y = mx + b\), solve for \(x\).

11. \(y = mx + b\), solve for \(b\).

12. \(4x - 2y = 10\), solve for \(y\).

Distributing & Factoring

13. \(A = P + Prt\), solve for \(P\).

14. \(S = 2lw + 2lh + 2wh\), solve for \(h\).

15. \(L = a + (n-1)d\), solve for \(n\).

16. \(ax + bx = c\), solve for \(x\).

17. \(S = \dfrac{n}{2}(a + l)\), solve for \(a\).

18. \(P = a + b + c\), solve for \(b\).
