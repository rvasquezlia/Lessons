Guided Solving Ladder

How this page works This is a supplemental page. Every worked example below walks through the same four-question ladder every time you take a step, and repeats the ladder as many times as needed until the target variable is completely alone. Read the ladder out loud to yourself before you try the exercises at the bottom.
The Question Ladder
Every time you take a step toward isolating a variable, ask yourself the same four questions, in this order. Keep climbing the ladder - repeating the four questions for a new obstruction - until the last question's answer is "yes."
The Four Questions (repeat as many times as needed)
#QuestionWhat it's asking
1What's the variable I need to isolate?Name the target letter. It doesn't change round to round.
2What is obstructing me from doing so?Name whatever is attached to the target variable right now.
3What is it doing?Name the operation - adding, subtracting, multiplying, or dividing.
4What's the inverse operation to remove it?Name the opposite operation, then apply it to both sides.

Apply question 4's answer to both sides, simplify, and then ask: "Is the variable now isolated?" If not, the whole ladder repeats on whatever is obstructing it next.

One extra question, for formulas where the target variable shows up more than once: if you can't answer question 2 with a single obstruction because the variable is attached to two or more terms, stop and ask instead - "Can one inverse operation remove all of these at once?" The answer is no, so the move is to factor the variable out of every term it appears in first. That turns the sum into a product, and now the variable appears exactly once - multiplied by everything in the parentheses - so the ladder above finishes the job.
Ten Worked Examples
Examples 1-3 take one trip up the ladder (one step, one appearance). Examples 4-7 take two trips up the ladder (multi-step, one appearance). Examples 8-10 need the factoring question first, because the target variable appears more than once.
1. \(A = bh\), solve for \(h\) One Step
Round 1
What's the variable I need to isolate?\(h\)
What is obstructing me from doing so?\(b\)
What is \(b\) doing?Multiplying
What's the inverse operation to remove it?Division
\(\dfrac{A}{b} = \dfrac{bh}{b}\)
\(h = \dfrac{A}{b}\)
Is \(h\) now isolated? Yes.
2. \(C = 2\pi r\), solve for \(r\) One Step
Round 1
What's the variable I need to isolate?\(r\)
What is obstructing me from doing so?\(2\pi\)
What is \(2\pi\) doing?Multiplying
What's the inverse operation to remove it?Division
\(\dfrac{C}{2\pi} = \dfrac{2\pi r}{2\pi}\)
\(r = \dfrac{C}{2\pi}\)
Is \(r\) now isolated? Yes.
3. \(V = lwh\), solve for \(l\) One Step
Round 1
What's the variable I need to isolate?\(l\)
What is obstructing me from doing so?\(wh\)
What is \(wh\) doing?Multiplying
What's the inverse operation to remove it?Division
\(\dfrac{V}{wh} = \dfrac{lwh}{wh}\)
\(l = \dfrac{V}{wh}\)
Is \(l\) now isolated? Yes.
4. \(y = mx + b\), solve for \(x\) Multi-Step
Round 1
What's the variable I need to isolate?\(x\)
What is obstructing me from doing so?\(b\) adding, and \(m\) multiplying
What's the first obstruction to undo?\(b\) adding
What is \(b\) doing?Adding
What's the inverse operation to remove it?Subtraction
\(y - b = mx + b - b\)
\(y - b = mx\)
Is \(x\) now isolated? No. Keep going - see next step.
Round 2
What's the variable I need to isolate?\(x\)
What is obstructing me from doing so?\(m\)
What is \(m\) doing?Multiplying
What's the inverse operation to remove it?Division
\(\dfrac{y-b}{m} = \dfrac{mx}{m}\)
\(x = \dfrac{y-b}{m}\)
Is \(x\) now isolated? Yes.
5. \(ax + by = c\), solve for \(b\) Multi-Step
Round 1
What's the variable I need to isolate?\(b\)
What is obstructing me from doing so?\(ax\) adding, and \(y\) multiplying
What's the first obstruction to undo?\(ax\) adding
What is \(ax\) doing?Adding
What's the inverse operation to remove it?Subtraction
\(ax - ax + by = c - ax\)
\(by = c - ax\)
Is \(b\) now isolated? No. Keep going - see next step.
Round 2
What's the variable I need to isolate?\(b\)
What is obstructing me from doing so?\(y\)
What is \(y\) doing?Multiplying
What's the inverse operation to remove it?Division
\(\dfrac{by}{y} = \dfrac{c-ax}{y}\)
\(b = \dfrac{c-ax}{y}\)
Is \(b\) now isolated? Yes.
6. \(P = 2l + 2w\), solve for \(w\) Multi-Step
Round 1
What's the variable I need to isolate?\(w\)
What is obstructing me from doing so?\(2l\) adding, and \(2\) multiplying
What's the first obstruction to undo?\(2l\) adding
What is \(2l\) doing?Adding
What's the inverse operation to remove it?Subtraction
\(P - 2l = 2l - 2l + 2w\)
\(P - 2l = 2w\)
Is \(w\) now isolated? No. Keep going - see next step.
Round 2
What's the variable I need to isolate?\(w\)
What is obstructing me from doing so?\(2\)
What is \(2\) doing?Multiplying
What's the inverse operation to remove it?Division
\(\dfrac{P-2l}{2} = \dfrac{2w}{2}\)
\(w = \dfrac{P-2l}{2}\)
Is \(w\) now isolated? Yes.
7. \(F = \dfrac{9}{5}C + 32\), solve for \(C\) Multi-Step
Round 1
What's the variable I need to isolate?\(C\)
What is obstructing me from doing so?\(32\) adding, and \(\dfrac{9}{5}\) multiplying
What's the first obstruction to undo?\(32\) adding
What is \(32\) doing?Adding
What's the inverse operation to remove it?Subtraction
\(F - 32 = \dfrac{9}{5}C + 32 - 32\)
\(F - 32 = \dfrac{9}{5}C\)
Is \(C\) now isolated? No. Keep going - see next step.
Round 2
What's the variable I need to isolate?\(C\)
What is obstructing me from doing so?\(\dfrac{9}{5}\)
What is \(\dfrac{9}{5}\) doing?Multiplying
What's the inverse operation to remove it?Multiplying by its reciprocal, \(\dfrac{5}{9}\)
\(\dfrac{5}{9}(F - 32) = \dfrac{5}{9}\cdot\dfrac{9}{5}C\)
\(C = \dfrac{5}{9}(F - 32)\)
Is \(C\) now isolated? Yes.
8. \(A = P + Prt\), solve for \(P\) Factoring
Round 1 - Factoring Question
What's the variable I need to isolate?\(P\)
What is obstructing me from doing so?\(P\) appears in two terms: \(P\) and \(Prt\)
Can one inverse operation remove both at once?No
What do I do instead?Factor \(P\) out of the right side
\(A = P(1 + rt)\)
Is \(P\) now isolated? No, but it now appears only once. Keep going - see next step.
Round 2
What's the variable I need to isolate?\(P\)
What is obstructing me from doing so?\((1+rt)\)
What is \((1+rt)\) doing?Multiplying
What's the inverse operation to remove it?Division
\(\dfrac{A}{1+rt} = \dfrac{P(1+rt)}{1+rt}\)
\(P = \dfrac{A}{1+rt}\)
Is \(P\) now isolated? Yes.
9. \(S = 2lw + 2lh + 2wh\), solve for \(h\) Factoring
Round 1
What's the variable I need to isolate?\(h\)
What is obstructing me from doing so?\(2lw\) adding (no \(h\) in it), plus \(2lh\) and \(2wh\) (both have \(h\))
What's the first obstruction to undo?\(2lw\) adding, since it has no \(h\) in it at all
What's the inverse operation to remove it?Subtraction
\(S - 2lw = 2lw - 2lw + 2lh + 2wh\)
\(S - 2lw = 2lh + 2wh\)
Is \(h\) now isolated? No. Keep going - see next step.
Round 2 - Factoring Question
What is obstructing me from doing so?\(h\) still appears in two terms: \(2lh\) and \(2wh\)
Can one inverse operation remove both at once?No
What do I do instead?Factor \(h\) out of the right side
\(S - 2lw = h(2l + 2w)\)
Is \(h\) now isolated? No, but it now appears only once. Keep going - see next step.
Round 3
What is obstructing me from doing so?\((2l+2w)\)
What is \((2l+2w)\) doing?Multiplying
What's the inverse operation to remove it?Division
\(\dfrac{S-2lw}{2l+2w} = \dfrac{h(2l+2w)}{2l+2w}\)
\(h = \dfrac{S-2lw}{2l+2w}\)
Is \(h\) now isolated? Yes.
10. \(ax + bx = c\), solve for \(x\) Factoring
Round 1 - Factoring Question
What's the variable I need to isolate?\(x\)
What is obstructing me from doing so?\(x\) appears in two terms: \(ax\) and \(bx\)
Can one inverse operation remove both at once?No
What do I do instead?Factor \(x\) out of the left side
\(x(a+b) = c\)
Is \(x\) now isolated? No, but it now appears only once. Keep going - see next step.
Round 2
What is obstructing me from doing so?\((a+b)\)
What is \((a+b)\) doing?Multiplying
What's the inverse operation to remove it?Division
\(\dfrac{x(a+b)}{a+b} = \dfrac{c}{a+b}\)
\(x = \dfrac{c}{a+b}\)
Is \(x\) now isolated? Yes.
Exercise Battery (15 Problems)
Work each problem on paper using the Question Ladder from Tab 1, then enter only the expression for the target variable in the math box - not "x =", just what goes on the other side. For a fraction, type / to open the fraction template and build \(\dfrac{d}{t}\) visually. Each item gives you up to 2 tries before showing the correct rearrangement.
Typing Key: Greek Letters & Symbols

Your keyboard can't type Greek letters, so spell them out instead. The answer checker reads these the same as the real symbol.

SymbolType it asShows up in
\(\pi\) (pi)piCircle and cylinder formulas
\(\sigma\) (sigma)sigmaStatistics: z-scores
\(\mu\) (mu)muStatistics: z-scores
\(\theta\) (theta)thetaAngles

Everything else types normally: use / for a fraction bar, ^ for an exponent (e.g. v^2 for \(v^2\)), and parentheses ( ) around anything that belongs together in a numerator or denominator.

Formulas From Other Classes
Literal equations aren't just an Algebra I thing - you'll rearrange formulas exactly like this in Science, Geometry, and even Financial Math. Same Question Ladder, same four questions, just a different subject's letters.
