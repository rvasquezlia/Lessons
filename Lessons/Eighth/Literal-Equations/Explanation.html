Same Toolkit, New Look
You already know how to solve \(2x + 3 = 11\). A literal equation like \(y = mx + b\) uses the exact same moves - subtract, then divide - the only difference is that the numbers around \(x\) have been replaced with letters. Watch the two side by side.

Numeric: solve for \(x\)

\(2x + 3 = 11\)
Subtract 3 from both sides: \(2x = 8\)
Divide both sides by 2: \(x = 4\)

Literal: solve for \(x\)

\(y = mx + b\)
Subtract \(b\) from both sides: \(y - b = mx\)
Divide both sides by \(m\): \(x = \dfrac{y-b}{m}\)
Prove It's the Same Answer

Plug \(y=11\), \(m=2\), \(b=3\) into the literal answer: \(x = \dfrac{11-3}{2} = \dfrac{8}{2} = 4\). Same \(x\) as the numeric problem, because it's the same equation - \(2x+3=11\) is just \(y=mx+b\) with the letters replaced by these particular numbers.

The misconception to drop right now: the other letters are not the answer, and they are not "in the way." Treat every letter you're not solving for exactly like you'd treat a number - move it with the same properties of equality, and never try to combine it with a letter it doesn't match (you can't add \(m\) and \(b\), any more than you could add an apple and an orange). Once you stop looking for "the number" and start looking for "the target letter alone," literal equations are just equations you already know how to solve.
Quick Refresher: Inverse Operations
If the equation shows...InverseAction to take on BOTH sides
Addition (\(+\,b\))↔Subtract \(b\)
Subtraction (\(-\,b\))↔Add \(b\)
Multiplication (\(mx\))↔Divide by \(m\)
Division (\(\dfrac{x}{a}\))↔Multiply by \(a\)
Solving for a Variable That Appears Once
Start with the easiest case: the letter you want shows up exactly once. Isolate it the same way you would in a two-step numeric equation - there's just nothing to combine, since every other letter already stands alone.

Worked Example: Area of a Rectangle

\(A = lw\)
Divide both sides by \(w\) (the inverse of multiplying by \(w\)): \(\dfrac{A}{w} = l\)
\(l = \dfrac{A}{w}\)

Check it with numbers

If \(A = 48\) and \(w = 6\): \(l = \dfrac{48}{6} = 8\). Substitute back into the original: \(8 \times 6 = 48\) - both forms agree.

Worked Example: Distance, Rate, and Time

\(d = rt\), solve for \(t\)
Divide both sides by \(r\): \(\dfrac{d}{r} = t\)
\(t = \dfrac{d}{r}\)
\(d = rt\), solve for \(r\)
Divide both sides by \(t\): \(\dfrac{d}{t} = r\)
\(r = \dfrac{d}{t}\)

Multi-Step Literal Equations
When your target letter has something added or subtracted and multiplied onto it, undo them in reverse order - exactly like a two-step numeric equation: addition/subtraction first, then multiplication/division.

Worked Example: Perimeter of a Rectangle

\(P = 2l + 2w\), solve for \(w\)
Subtract \(2l\) from both sides: \(P - 2l = 2w\)
Divide both sides by 2: \(w = \dfrac{P - 2l}{2}\)
Check it with numbers

If \(P = 30\) and \(l = 8\): \(w = \dfrac{30 - 16}{2} = \dfrac{14}{2} = 7\). Check in the original: \(2(8) + 2(7) = 16 + 14 = 30\), which matches.

Worked Example: Temperature Conversion

\(F = \dfrac{9}{5}C + 32\), solve for \(C\)
Subtract 32 from both sides: \(F - 32 = \dfrac{9}{5}C\)
Multiply both sides by \(\dfrac{5}{9}\) (the inverse of multiplying by \(\dfrac{9}{5}\)): \(C = \dfrac{5}{9}(F - 32)\)
Check it with numbers

If \(F = 68\): \(C = \dfrac{5}{9}(68 - 32) = \dfrac{5}{9}(36) = 20\). Check in the original: \(\dfrac{9}{5}(20) + 32 = 36 + 32 = 68\), which matches.

Distributing & Factoring to Solve for a Variable
Sometimes your target letter appears in more than one term. When that happens, isolating it in one step isn't possible - you have to factor it out first, turning a sum into a product, before you can divide it away.

Worked Example: Total Amount With Simple Interest

\(A = P + Prt\), solve for \(P\)
Notice \(P\) appears in both terms on the right. There's no single inverse operation that isolates it yet.
Factor \(P\) out of the right side: \(A = P(1 + rt)\)
Now \(P\) appears once, multiplied by \((1+rt)\). Divide both sides by \((1+rt)\): \(P = \dfrac{A}{1 + rt}\)
Check it with numbers

If \(A = 1150\), \(r = 0.05\), \(t = 3\): \(P = \dfrac{1150}{1 + (0.05)(3)} = \dfrac{1150}{1.15} = 1000\). Check in the original: \(1000 + 1000(0.05)(3) = 1000 + 150 = 1150\), which matches.

Worked Example: Surface Area of a Rectangular Prism

\(S = 2lw + 2lh + 2wh\), solve for \(h\)
\(h\) appears in two terms (\(2lh\) and \(2wh\)) but not the third. Subtract the term without \(h\) first: \(S - 2lw = 2lh + 2wh\)
Factor \(h\) out of the right side: \(S - 2lw = h(2l + 2w)\)
Divide both sides by \((2l+2w)\): \(h = \dfrac{S - 2lw}{2l + 2w}\)
Check it with numbers

If \(l = 4\), \(w = 3\), \(S = 94\): \(h = \dfrac{94 - 2(4)(3)}{2(4) + 2(3)} = \dfrac{94 - 24}{8 + 6} = \dfrac{70}{14} = 5\). Check in the original: \(2(4)(3) + 2(4)(5) + 2(3)(5) = 24 + 40 + 30 = 94\), which matches.

Worked Example: Arithmetic Sequences

\(L = a + (n-1)d\), solve for \(n\)
Subtract \(a\) from both sides: \(L - a = (n-1)d\)
Divide both sides by \(d\): \(\dfrac{L-a}{d} = n - 1\)
Add 1 to both sides: \(n = \dfrac{L-a}{d} + 1\)
Check it with numbers

If \(L = 29\), \(a = 5\), \(d = 3\): \(n = \dfrac{29-5}{3} + 1 = \dfrac{24}{3} + 1 = 8 + 1 = 9\). Check in the original: \(5 + (9-1)(3) = 5 + 24 = 29\), which matches. Notice this one didn't need factoring at all - \(n\) only appeared once inside the parentheses, so it's really a multi-step problem wearing a factoring costume. Always check how many times your target letter actually appears before assuming you need to factor.

Worked Applications: Simple Interest
One formula, four ways to use it. \(I = Prt\) has no addition or subtraction to undo, and every variable appears only once - so solving for any of the four letters is a single division.
Solve for \(P\): \(P = \dfrac{I}{rt}\)
Solve for \(r\): \(r = \dfrac{I}{Pt}\)
Solve for \(t\): \(t = \dfrac{I}{Pr}\)
Solve for \(I\): \(I = Prt\) (already solved)

Why Checking by Substitution Works

Every rearranged formula on this page was checked the same way: pick numbers for the letters you know, compute the target letter with your new formula, then plug everything back into the original formula. If both sides come out equal, your rearrangement is correct - this works because solving for a variable never changes which sets of numbers make the equation true, it only changes which letter is easiest to read the answer from.
