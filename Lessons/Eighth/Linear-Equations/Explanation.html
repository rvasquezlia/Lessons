Foundations: Properties of Equality & Inverse Operations
Before You Start: Integer Rules

Every equation below involves adding, subtracting, multiplying, or dividing negative numbers. If these rules are shaky, that's what will trip you up - not the algebra.

OperationThe Rule
AdditionSame signs: add the absolute values and keep the sign. (\(-3+(-5)=-8\))
Different signs: subtract the smaller absolute value from the larger, and keep the sign of the number with the larger absolute value. (\(-10+4=-6\))
SubtractionAdd the opposite: flip the subtraction to addition and change the sign of the second number, then follow the addition rule above. (\(5-(-2)\) becomes \(5+2=7\))
Multiplication & DivisionSame signs: the result is positive. Different signs: the result is negative.
The Golden Rule of Equations: an equation is a balanced scale. Whatever you do to one side, you have to do to the other, or the two sides stop being equal. Every method on this page comes back to that one idea.
Properties of Equality

These are the moves that are always legal - they're the reason you're allowed to add, subtract, multiply, or divide both sides of an equation without changing its solution.

  • Addition Property: if \(a = b\), then \(a + c = b + c\).
  • Subtraction Property: if \(a = b\), then \(a - c = b - c\).
  • Multiplication Property: if \(a = b\), then \(ac = bc\).
  • Division Property: if \(a = b\) and \(c \neq 0\), then \(\frac{a}{c} = \frac{b}{c}\).
Inverse Operations

Solving an equation means undoing whatever's been done to the variable, one operation at a time, using the matching inverse on both sides.

If the equation shows...InverseAction to take on BOTH sides
Addition (\(+5\))↔Subtract 5
Subtraction (\(-8\))↔Add 8
Multiplication (\(3x\))↔Divide by 3
Division (\(\frac{x}{4}\))↔Multiply by 4
Worked Example: One Inverse Operation, Visualized

\(x + 9 = 15\). Subtract 9 from both sides and the \(+9\) is gone, leaving \(x = 6\). The number line shows the same move: start at 15, step back 9, and land on the solution.

Solving Equations With the Variable on One Side
A linear equation with the variable on one side can always be solved by simplifying each side first (distribute, combine like terms), then using inverse operations in reverse order to isolate the variable.

When the Variable Disappears

Sometimes collecting variable terms eliminates the variable entirely. What's left tells you the answer:

\(2(x+3) = 2x + 7 \;\rightarrow\; 2x + 6 = 2x + 7 \;\rightarrow\; 6 = 7\). A false statement means no solution - no value of \(x\) works.

\(4(x+1) = 4x + 4 \;\rightarrow\; 4x + 4 = 4x + 4 \;\rightarrow\; 4 = 4\). A true statement means infinitely many solutions - every value of \(x\) works.

Classifying Solutions: One, None, or Infinitely Many?
Simplify both sides completely first. A false statement like \(6 = 7\) means no solution. A true statement like \(4 = 4\) means infinitely many solutions. Anything else simplifies to exactly one solution.

Worked Applications: Writing Equations From Words
The 4-Step Method
  1. Define the Variable: choose a letter and state exactly what it represents.
  2. Write the Equation: use translation keywords to build your equation.
  3. Solve: use inverse operations to isolate the variable, performing the same operation on both sides.
  4. Interpret: write your final answer as a complete sentence with units.
Resolved Example 1: The Taxi Ride

A taxi ride costs a flat fee of \$5.00 plus \$2.00 per mile. If the total cost was \$17.00, how many miles was the ride?

1. Define Variable: Let \(m\) = the number of miles.

2. Equation: \[2m + 5 = 17\]

3. Solve: \[2m = 12 \rightarrow m = 6\]

4. Interpret: The taxi ride was 6 miles long.

Resolved Example 2: Mixture Investigation

A chemistry lab needs to prepare 12 liters of a 30% acid solution by combining a 50% acid solution with a 20% acid solution.

1. Define Variable: Let \(x\) = liters of 50% solution, so \((12-x)\) = liters of 20% solution.

2. Equation: \[0.5x + 0.2(12-x) = 0.3(12)\]

3. Solve: \[0.5x + 2.4 - 0.2x = 3.6 \rightarrow 0.3x + 2.4 = 3.6 \rightarrow 0.3x = 1.2 \rightarrow x = 4\]

4. Interpret: 4 liters of the 50% solution and 8 liters of the 20% solution are needed.

Resolved Example 3: Work & Time

Print Shop A's printer produces 5 pages per minute. Print Shop B's printer produces 8 pages per minute. Working at the same time, the two printers must produce a combined order of 260 pages.

1. Define Variable: Let \(x\) = minutes both printers run.

2. Equation: \[5x + 8x = 260\]

3. Solve: \[13x = 260 \rightarrow x = 20\]

4. Interpret: Working together, the printers finish the order in 20 minutes.
