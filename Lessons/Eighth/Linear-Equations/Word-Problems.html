Mixture & Work-Rate Applications
Multidisciplinary connection: Science & Mathematical Modeling, Engineering & Logical Reasoning. Linear equations model relationships between measurable quantities - here, a chemistry mixture and a combined work rate.

Mixture Investigation

A chemistry lab needs to prepare \(12\) liters of a \(30\%\) acid solution by combining a \(50\%\) acid solution with a \(20\%\) acid solution.

Task: if \(x\) is the number of liters of \(50\%\) solution used, then \((12 - x)\) is the number of liters of \(20\%\) solution used. The equation is \(0.5x + 0.2(12 - x) = 0.3(12)\). Solve for \(x\), then find how much \(20\%\) solution is needed.

Work & Time Scenario

Print Shop A's printer produces \(5\) pages per minute. Print Shop B's printer produces \(8\) pages per minute. Working at the same time, the two printers must produce a combined order of \(260\) pages.

Task: write and solve an equation for \(x\), the number of minutes it takes both printers, working together, to complete the order.

Real-Life Application: Cost Comparison Scenarios
Set the two total-cost expressions equal to each other, solve for the number of months, then use the result to make a recommendation.

Comparing Two Gym Plans

Gym A charges a \(\$40\) sign-up fee plus \(\$25\) per month. Gym B charges no sign-up fee, but \(\$33\) per month.

Task: after how many months, \(x\), do both gyms cost the same total amount?

More Practice: Break-Even Scenarios (Gym Plans)

For each pair of plans, find the number of months, \(x\), where both cost the same total amount.

Choosing an Internet Provider

Provider A charges a \(\$45\) setup fee plus \(\$20\) per month. Provider B charges a \(\$65\) setup fee plus \(\$15\) per month.

Task: after how many months, \(x\), do both providers cost the same total amount? If a customer plans to keep service for a full year, which provider costs less overall?

Real-Life Application: Savings & Billing Comparisons
A false statement like \(6 = 7\) means no solution. A true statement like \(4 = 4\) means infinitely many solutions. Here, classify what each comparison means for the two people or plans involved.

Two Savings Plans

Friend 1 starts with \(\$50\) and saves \(\$10\) per week: total after \(x\) weeks is \(50 + 10x\). Friend 2 starts with \(\$80\) and also saves \(\$10\) per week: total after \(x\) weeks is \(80 + 10x\).

Task: set \(50 + 10x = 80 + 10x\) and classify it. What does that classification mean for these two friends' savings?

Two Ways to Write the Same Plan

A phone plan's monthly cost is written two different ways by two different billing systems: \(2(3x + 5)\) and \(6x + 10\), where \(x\) is gigabytes of extra data used.

Task: set \(2(3x+5) = 6x+10\) and classify it. What does that classification mean about the two billing systems?
