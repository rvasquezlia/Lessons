Sign Rules
  • Addition: same signs → add, keep sign. Different signs → subtract, keep the larger's sign.
  • Subtraction: add the opposite: \(5-(-2) \rightarrow 5+2=7\).
  • Multiply/Divide: same signs → positive. Different signs → negative.
The Golden Rule: whatever you do to one side, you must do to the other.
The Question Ladder
  • What's the variable?
  • What's obstructing it?
  • What's it doing?
  • What's the inverse? Apply to both sides.

Classification Rules

False (\(6=7\)) → no solution. True (\(4=4\)) → infinitely many. Anything else → one solution.
