Key Vocabulary: Properties of Equality & Inverse Operations

Lessons 1-2 & 1-3 · HSA.REI.A.1, HSA.REI.B.3 & MP.7

Every equation you solve rests on one idea: whatever you do to one side of an equation, you must do to the other side, or the equation stops being true. Before working with multi-step equations, confirm you can name the property behind each move.
COPY INTO MATH NOTEBOOK — Properties of Equality
  • Addition Property: if \(a = b\), then \(a + c = b + c\).
  • Subtraction Property: if \(a = b\), then \(a - c = b - c\).
  • Multiplication Property: if \(a = b\), then \(ac = bc\).
  • Division Property: if \(a = b\) and \(c \neq 0\), then \(\dfrac{a}{c} = \dfrac{b}{c}\).
COPY INTO MATH NOTEBOOK — Key Terms
  • Linear equation: an equation where the variable has an exponent of 1; its graph is a straight line.
  • Solution: the value(s) of the variable that make the equation true.
  • Inverse operation: the operation that "undoes" another (addition ↔ subtraction; multiplication ↔ division).
  • Distributive Property: \(a(b + c) = ab + ac\) — multiply the factor outside the parentheses by each term inside.
  • Like terms: terms with the same variable raised to the same power; they can be combined.
  • One solution: exactly one value of \(x\) satisfies the equation.
  • No solution: the equation simplifies to a false statement (e.g. \(0 = 5\)).
  • Infinitely many solutions: the equation simplifies to a true statement (e.g. \(0 = 0\)).

Real-World Examples

  • Wages: You earn $12 per hour plus a $20 bonus. To find how many hours you worked if you earned $92: \(12h + 20 = 92\).
  • Perimeter: A rectangle has perimeter 48 cm and length 14 cm. Find the width: \(2(14) + 2w = 48\).
  • Distance: Two cars 300 km apart drive toward each other at 60 km/h and 90 km/h. When do they meet? \(60t + 90t = 300\).

Warning: "Less Than" Reverses the Order

Most subtraction phrases keep the same word order as the equation, but "less than" and "subtracted from" flip it. Read the numbers in the order they're written, then write the expression backwards:

  • "5 less than a number" → \(x - 5\) (not \(5 - x\))
  • "a number subtracted from 5" → \(5 - x\)
  • "5 decreased by a number" → \(5 - x\) (this one does not flip)

Test it: if a number is 5 less than 20, is it 15 or −15? It's 15, so "5 less than \(x\)" must mean \(x - 5\), confirming the flip.

COPY INTO MATH NOTEBOOK - Setting Up Word Problems
  • Consecutive integers: \(x,\ x+1,\ x+2, \ldots\) (e.g. three consecutive integers: \(x, x+1, x+2\)).
  • Consecutive even or odd integers: \(x,\ x+2,\ x+4, \ldots\) (skip by 2, even or odd).
  • "In \(n\) years" (age, future): add \(n\) — current age \(x\) becomes \(x + n\).
  • "\(n\) years ago" (age, past): subtract \(n\) — current age \(x\) becomes \(x - n\).
