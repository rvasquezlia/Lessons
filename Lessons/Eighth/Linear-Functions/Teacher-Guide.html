Topic Overview: Linear Functions
8-PreAP only - distinct from Solving Linear Equations and Literal Equations. Those two units solve equations for one unknown; this unit treats a linear equation as a function - an input/output rule - and covers domain/range, slope, function notation, and slope-intercept form.
  • Six standalone pages: Review, Vocabulary & Literacy, Explanation, Practice Set, Word Problems, Test Prep.
  • Pages don't link to each other - share each one directly (e.g. one Google Classroom post per page) in the order you want.

Standards & Objectives

HSF.IF.A.1, HSF.IF.A.2, HSF.IF.B.5, HAS.CED.A.2, HSS.ID.C.7 & MP.4, MP.6, MP.7.

  • Determine whether a relation is a function; identify domain and range.
  • Find the slope between two points and interpret it as a rate of change.
  • Write and graph linear equations in slope-intercept form.
  • Use function notation to evaluate functions and to model real-world situations.
Common Misconceptions to Watch For
  • Substituting into the wrong place in \(f(x)\), or skipping order of operations after substituting.
  • Flipping which coordinate is \((x_1,y_1)\) vs. \((x_2,y_2)\) in the slope formula and losing the sign.
  • Assuming any table of ordered pairs is automatically a function, without checking for a repeated input.
  • Confusing a proportional relationship (\(y=kx\)) with every linear relationship (\(y=mx+b\)).

Metacognition & Discussion

Reflection prompts and small-group discussion questions to use alongside any of the six pages - none of this is graded content on a student page, it's for you to drop into a warm-up, an exit ticket, or a mid-lesson pause.

Reflection Prompts (use as an exit ticket or journal stem)
  • "When I evaluated \(f(x)\) today, did I substitute the input in every place \(x\) appeared, and did I follow order of operations after that?" (see Misconception #1 on the Overview tab)
  • "When I found a slope today, how did I keep track of which point was \((x_1,y_1)\) and which was \((x_2,y_2)\)?"
  • "Given a table of values, what's the first thing I check to decide whether it's a function?"
  • "What's the difference between a proportional relationship and a linear relationship - and is every proportional relationship also linear?"
  • "Where might I actually use function notation outside of math class - a recipe, a paycheck, a phone bill?"

1. \(f(x)=2x+1\) and \(g(x)=3x-4\). Find the value of \(x\) that makes \(f(x)=g(x)\), then verify.\(2x+1=3x-4 \Rightarrow x=\mathbf{5}\). Check: \(f(5)=11\) and \(g(5)=11\) - both functions agree at \(x=5\).

Challenge Bank

Extra problems for early finishers or homework extension, harder than anything graded on the six pages - everything below is digital, no printed materials needed. Click a problem to reveal its full solution.

C1. A function is defined by \(f(x)=-3x+7\). Find \(x\) when \(f(x)=-14\).

Show solution

\(-3x+7=-14\). Subtract 7: \(-3x=-21\). Divide by \(-3\): \(x=\mathbf{7}\). Check: \(f(7)=-3(7)+7=-21+7=-14\).

C2. Two points on a line are \((a,5)\) and \((a+4,13)\), where \(a\) is any real number. Find the slope.

Show solution

Slope \(=\dfrac{13-5}{(a+4)-a}=\dfrac{8}{4}=\mathbf{2}\). The \(a\) cancels out entirely - the slope is the same no matter what \(a\) is, since both points always sit exactly 4 apart horizontally and 8 apart vertically.

C3. A table shows \(x: 0,1,2,3\) and \(y: 5,5,5,5\). Is this relation a function? Is it proportional? Explain both.

Show solution

Function: yes - every input maps to exactly one output. Proportional: no - a proportional relationship must pass through the origin, but here \(x=0\) gives \(y=5\), not \(y=0\). This is a constant function (\(y=5\)), a special case of linear but not proportional.

C4. A gym charges a \(\$50\) signup fee plus \(\$30\)/month. Write a cost function \(C(m)\), then find the fewest number of whole months before the total cost exceeds \(\$500\).

Show solution

\(C(m)=30m+50\). Set \(30m+50 > 500\): \(30m>450\), so \(m>15\). Since \(m\) must be a whole number of months, the total first exceeds \$500 at \(m=\mathbf{16}\) months. Check: \(C(15)=500\) exactly (not yet over), \(C(16)=530\).

C5. Given \(f(x)=2x-3\), find the value of \(k\) that makes \(f(k)=15\) true.

Show solution

\(2k-3=15\). Add 3: \(2k=18\). Divide by 2: \(k=\mathbf{9}\). Check: \(f(9)=2(9)-3=18-3=15\).
