Concept Review: Every Rule in One Place
What to do on this tab Skim the rules below, then answer the 4 Check Your Understanding problems.
1. Function & Domain/Range

A relation is a function only if every input has exactly one output. The domain is every possible input; the range is every possible output.

2. Slope

\(m = \dfrac{y_2-y_1}{x_2-x_1}\). Horizontal line: \(m=0\). Vertical line: undefined.

3. Function Notation

\(f(a)\) means substitute \(a\) for \(x\) and simplify.

Common Misconceptions to Watch For
  • Substituting into the wrong place in \(f(x)\), or forgetting order of operations.
  • Mixing up which coordinate is \(x_1\)/\(x_2\) in the slope formula, flipping the sign.
  • Assuming any table of ordered pairs is automatically a function.
