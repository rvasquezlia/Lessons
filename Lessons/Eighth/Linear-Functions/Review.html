Why We're Learning This
So far, an equation like \(2x - 7 = 9\) has had exactly one unknown to solve for. A function reframes that same kind of expression as a rule: put a number in, get a number out, following a consistent pattern. Linear Functions is about reading, writing, and interpreting those rules - in tables, graphs, equations, and real-world situations.
Building on Solving Equations

Every skill from Solving Linear Equations still applies here - especially isolating a variable and using inverse operations. This topic layers a new idea on top: instead of solving for one specific value, you'll describe the whole relationship between two changing quantities at once.

Vocabulary You Need First
These words describe how two quantities relate to each other - the foundation this whole topic is built on. (Words like function notation, domain, and range are brand new this topic, so they're taught in the Vocabulary & Literacy page, not here.)
Input / Independent Variable

The quantity you choose or control. Often shown as \(x\).

The number of hours you work
Output / Dependent Variable

The quantity that results from the input. Often shown as \(y\).

The money you earn
Rate of Change

How much the output changes each time the input increases by 1.

$12 more for each additional hour worked
Initial Value

The output when the input is 0 - the starting point of the relationship.

$20 already in the register before any sales
Linear vs. Proportional Relationships
Every proportional relationship is linear, but not every linear relationship is proportional. The Celsius-Fahrenheit conversion below is the classic example of a linear relationship that isn't proportional.
Celsius to Fahrenheit
°C°F
032
541
1050
1559
2068

Every time °C increases by 5, °F increases by 9 - a constant rate of change, so the relationship is linear. But 0°C does not correspond to 0°F, so the graph does not pass through the origin - the relationship is not proportional. Its equation is \(F = \frac{9}{5}C + 32\), in the form \(y = mx + b\) with \(b \neq 0\).

The Two Forms

Proportional: \(y = kx\) - graph passes through \((0,0)\), and \(\frac{y}{x}\) is always the same constant \(k\). Linear (general form): \(y = mx + b\) - graph is a straight line with slope \(m\) and \(y\)-intercept \(b\); proportional is the special case where \(b = 0\).
