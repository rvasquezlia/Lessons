Key Vocabulary: Linear Functions
Every term below shows up in this topic. Read through them once, then come back any time a word trips you up.

Functions

Relation

Any set of ordered pairs matching inputs to outputs.

\(\{(1,2), (1,5), (3,4)\}\)
Function

A relation where every input has exactly one output.

\(\{(1,2), (2,5), (3,4)\}\) is a function
Domain

The complete set of possible input (\(x\)) values.

For \(\{(1,2), (2,5)\}\), the domain is \(\{1, 2\}\)
Range

The complete set of possible output (\(y\)) values.

For \(\{(1,2), (2,5)\}\), the range is \(\{2, 5\}\)
Vertical Line Test

If any vertical line crosses a graph more than once, the graph is not a function.

A circle fails the test; a line passes it

Function Notation

Function Notation

Writing a function's rule as \(f(x)\) ("f of x") instead of \(y\), naming which function produced the output.

\(f(x) = 2x + 1\)
Evaluating a Function

Substituting a specific input value in for \(x\) and simplifying.

\(f(3) = 2(3) + 1 = 7\)
Linear Function

A function whose graph is a straight line - can be written \(f(x) = mx + b\).

\(f(x) = -3x + 5\)

Slope & Equation Forms

Slope

The rate of change between two points on a line: \(m = \frac{y_2 - y_1}{x_2 - x_1}\).

Through \((1,2)\) and \((3,8)\): \(m = 3\)
y-Intercept

The point where a line crosses the \(y\)-axis - the output when \(x = 0\).

In \(y = 4x + 7\), the y-intercept is 7
Slope-Intercept Form

\(y = mx + b\), where \(m\) is the slope and \(b\) is the y-intercept.

\(y = -2x + 5\)
Point-Slope Form

\(y - y_1 = m(x - x_1)\), used to write an equation from a slope and one point.

\(y - 3 = 2(x - 1)\)
