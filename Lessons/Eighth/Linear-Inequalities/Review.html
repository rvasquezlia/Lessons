Review: Isolating a Variable & Signed Numbers

Standards: HSA.CED.A.1, HSA.REI.A.1, HSA.REI.B.3

Everything you need to remember before we start Solving Linear Inequalities

How this page works Nothing here is graded except the "Are You Ready?" tab – this is a warm-up, and it's an important one. Solving an inequality uses the exact same isolate-the-variable process you just learned for equations, plus exactly one new rule: flip the symbol when you multiply or divide by a negative. That new rule depends completely on the integer sign rules from earlier grades, so this page reviews both pieces before the new content begins.
Why We're Reviewing This First
An inequality is solved almost exactly like an equation: use inverse operations to isolate the variable. If that skill is already solid from the Linear Equations topic, this whole unit is really just learning one new rule on top of it - flip the symbol when you multiply or divide by a negative number. If isolating a variable still feels shaky, that one new rule will be much harder to apply correctly, because you'll be juggling two skills instead of one.
The Big Idea

Every rule for solving an equation still works for an inequality, with exactly one exception: multiplying or dividing both sides by a negative number reverses which side is bigger, so the inequality symbol has to reverse too. That single exception - not a whole new method - is what makes this topic different from the last one.

Vocabulary Quick Reference
A fast reference for the words used on this page. For the full glossary (including graphing vocabulary like boundary point and solution set) plus translation practice, see this topic's own Vocabulary & Literacy page.
Variable

A letter that represents an unknown or changing number.

The \(x\) in \(2x - 5\)
Isolate the Variable

The goal of solving: use inverse operations until the variable stands alone on one side.

\(3x > 15 \rightarrow x > 5\)
Inequality

A mathematical sentence comparing two expressions with \(<\), \(>\), \(\leq\), or \(\geq\).

\(x + 3 > 10\)
The Four Symbols

\(>\) greater than, \(<\) less than, \(\geq\) at least, \(\leq\) at most.

"At least 5" is \(x \geq 5\)
Isolating the Variable: Equation Warm-Up
Before adding the flip rule, make sure the underlying process is automatic. Solve each equation below exactly as you did in the last topic - no inequalities yet.
The Question Ladder
  • What's the variable?
  • What's preventing it, and what is it doing (adding, subtracting, multiplying, dividing)?
  • What's the inverse operation? Apply it to both sides.
Worked Example: One-Step

Solve \(x + 7 = 15\). Subtract 7 from both sides: \(x = 8\).

Worked Example: Two-Step

Solve \(3x - 2 = 13\).

Step 1 - Add 2 to both sides: \(3x = 15\).

Step 2 - Divide both sides by 3: \(x = 5\).

The One Difference Coming Up

Every step above works identically for an inequality - except when the inverse operation is dividing or multiplying by a negative number. That single case is the entire new content of this topic, covered in depth on the Explanation page.

Number Lines & Signed Numbers Recap
The flip rule and graphing an inequality both depend on being fluent with negative numbers and number lines - the same skills from Integers and Rational Numbers.
Reading a Number Line

Numbers get larger moving to the right, and smaller moving to the left - this is true for negative numbers too. \(-2\) is greater than \(-5\), because \(-2\) sits to the right of \(-5\) on the number line.

Multiplying & Dividing Signed Numbers
SignsResult
Same signs (both positive, or both negative)Positive
Different signs (one positive, one negative)Negative
Why This Matters for the Flip Rule

Multiplying or dividing by a negative number swaps a value's sign - a swap big enough that it can change which of two numbers is "bigger." That's exactly why the inequality symbol has to flip: without flipping, the statement would no longer be true.
