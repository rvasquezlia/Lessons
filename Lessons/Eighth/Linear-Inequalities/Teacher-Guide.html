Topic Overview: Solving Linear Inequalities
Regular Eighth grade only - not shared with 8th Grade Pre-AP (Pre-AP's equivalent-level content lives in Eighth/Linear-Functions instead). This topic continues directly from Linear-Equations/Literal-Equations - same Topic 1 standards, same "isolate the variable" skill, plus exactly one new rule: flip the inequality symbol when multiplying or dividing by a negative.
  • Six pages: Review, Vocabulary & Literacy, Explanation, Practice Set, Word Problems, Test Prep.
  • Pages don't link to each other - share each one directly (e.g. one Google Classroom post per page) in the order you want. Suggested order: Review → Vocabulary & Literacy → Explanation → Practice Set → Word Problems → Test Prep.
  • Calculators are allowed this year.
  • Every answer on every page is a plain typed inequality (e.g. x > 5 or x <= -2, either ASCII or unicode ≥/≤ accepted) - no <math-field> visual editor on this topic, since an inequality's answer is a short symbolic token rather than a fraction or algebraic expression (see /CLAUDE.md's "Visual math input" notes for the site-wide rule this follows).

Standards & Objectives

HSA.CED.A.1 (create inequalities in one variable and use them to solve problems), HSA.REI.A.1 (justify each solving step), HSA.REI.B.3 (solve linear inequalities in one variable) - the identical standards set Linear-Equations carries, since both are Algebra I Topic 1 (Lessons 1-2 through 1-5 in the enVision Algebra 1 book).

  • Solve one-step, two-step, and multi-step linear inequalities in one variable.
  • Apply the flip rule correctly when multiplying or dividing by a negative number.
  • Graph an inequality's solution set on a number line, and read a solution set from a graph.
  • Translate real-world constraints ("at least," "at most," "more than," "fewer than") into inequalities and solve them.
Common Misconceptions to Watch For
  • Forgetting to flip when dividing/multiplying by a negative - by far the most common error across every page.
  • Flipping when it isn't needed - adding or subtracting a negative number never flips the symbol, only multiplying/dividing by one does. Test-Prep's own Error Analysis items are built specifically around this pair of opposite mistakes.
  • Distributing a negative multiplier incorrectly (e.g. \(-4(x+2)\) becoming \(-4x+2\) instead of \(-4x-8\)) - independent of the flip rule, but compounds with it in multi-step problems.
  • Confusing "fewer than"/"less than" (\(<\)) with "at most" (\(\leq\)), or "more than" (\(>\)) with "at least" (\(\geq\)) - the strict-vs-inclusive distinction is exactly what the Vocabulary & Literacy page's translation table targets.
  • Graphing the wrong circle type or the wrong direction - open vs. closed and left vs. right are graded as two independent sub-answers on Practice Set's Graphing Practice tab specifically because they're two independent mistakes.

Lesson-by-Lesson Guide

What each of the six pages covers, and what each tab inside it is for. Answer keys for every graded item already live inline on the student page itself - sign in there as a teacher and it unlocks automatically (see the howto note above), so this tab is about what to teach, not what to grade.

1. Review

Refreshes exactly the two prerequisite skills the flip rule depends on - isolating a variable (from Linear-Equations) and signed-number reasoning - before any new inequality content appears. Gate it with Tab 5's graded check before moving on.

2. Vocabulary & Literacy

Builds the actual language of this unit: inequality/solution-set/boundary-point terms, the four translation phrases (at least/at most/more than/fewer than), and graphing terms (open/closed circle). This is the page to assign before Explanation if a class struggles with word problems more than computation.

TabWhat it's about
1. Key VocabularyGlossary of inequality parts, graphing terms, and the real-world phrase list - the reference the other two tabs draw on.

3. Explanation

Worked examples only, no grading - the "watch me think through it" page. Built as a full Round-by-Round Question Ladder (Define it / What am I solving for / What's preventing me / single next move / check), the same format as Literal-Equations' Guided-Solving-Ladder, so a student who's used the ladder before recognizes the structure immediately.

TabWhat it's about
1. Symbols & Graphing BasicsWhat each symbol (\(<,\leq,>,\geq\)) means, and how a solution set looks on a number line (open vs. closed circle, direction of the ray).
2. One-Step & Two-StepSolving inequalities with no sign flip needed yet - isolating a variable when the coefficient is positive.
3. The Flip RuleThe one genuinely new rule in this whole unit: why the symbol flips when multiplying/dividing by a negative, with a from-scratch derivation (not just "memorize this"), plus a step-by-step arithmetic breakdown of what actually happens to the numbers each round.
4. Multi-Step InequalitiesDistributing, combining like terms, and variables on both sides - everything from Linear-Equations' own multi-step work, now with the flip rule layered on top when it applies.
5. Worked ApplicationsReal-world scenarios worked start to finish (define the variable, write the inequality, solve, interpret in context) - the bridge to Word Problems.
4. Practice Set

The main graded computation page - six tabs moving from no-flip warm-up to full multi-step, plus a dedicated flip-rule-only tab (the misconception this whole unit centers on gets its own isolated practice, not just mixed in with everything else) and both directions of graphing.

TabWhat it's about
1. Warm-UpOne-step inequalities, all positive coefficients - no flip decision required yet, purely a fluency check.
2. Two-Step & Multi-StepAdds a second operation and, later, distributing/combining - still mostly positive coefficients, so the flip rule isn't the focus here.
3. The Flip Rule FocusEvery item here requires dividing/multiplying by a negative - deliberately isolates the one skill students get wrong most, per the Common Misconceptions box on the Overview tab.
4. Graphing PracticeBoth directions of the graphing skill: describe a given graph as an inequality (Part A), and read a graph from a given inequality (Part B) - graded as two independent sub-skills (open/closed, left/right) since they're two independent mistakes.
5. Strategy ChallengeStudent picks one of several themed problem groups (no-flip / flip-required / distribute-then-flip) and works through it - see "Group Activities" in the Metacognition & Discussion tab for how to use this one with the whole class.
6. Error AnalysisGiven someone else's (wrong) solution, find the step where it broke and fix it - trains students to catch the flip-rule mistake in someone else's work, which is a different skill than avoiding it in their own.
5. Word Problems

Applies everything above to real scenarios - budgets/limits first (the most concrete, closest to Explanation's own worked applications), then pure phrase-translation scenarios, then genuinely mixed/challenge problems that require picking apart a two-plan comparison or rounding a fractional answer to a sensible whole number.

TabWhat it's about
1. Budgets & LimitsSet-up-and-solve scenarios with a clear "at most/no more than" cap (a trip budget, a weight limit) - the most scaffolded of the three tabs.
2. Requirement ScenariosPure translation - given a real-world requirement (a minimum height, a maximum speed), write and solve the inequality with no extra arithmetic layered on.
3. Mixed & ChallengeThe hardest tab: comparing two payment plans, minimizing packing weight, or finding a whole-number answer where the raw solve gives a fraction - these require reading closely, not just plugging into a formula.
6. Test Prep

The assessment-prep page - a full mixed review, a second error-analysis pass, a submit-only worksheet-style tab (no retry, closest to a real quiz), and a short exit-ticket readiness check you can use as a same-day formative signal.

TabWhat it's about

2. Error Analysis ReviewA second, harder pass at the same "find the wrong step" skill Practice Set's Tab 6 introduced.

Metacognition & Discussion

Reflection prompts and small-group discussion questions to use alongside any of the six pages - none of this is graded content on a student page, it's for you to drop into a warm-up, an exit ticket, or a mid-lesson pause.

Reflection Prompts (use as an exit ticket or journal stem)
  • "What's one moment today where I almost made the sign-flip mistake, and how did I catch it (or not)?"
  • "If I had to explain the flip rule to a 6th grader in one sentence, what would I say?"
  • "Which problem today took me the most tries? What did I actually change between attempts?"
  • "On a scale of 1-5, how confident am I graphing an inequality's solution set? What's one thing that would move me up a point?"
  • "Where in real life might I actually reach for an inequality instead of an equation?"
Leveled Small-Group Discussion Prompts
TierPrompt
Building UnderstandingTake turns explaining to your partner: why do we flip the inequality symbol only for multiplying or dividing by a negative, and never for adding or subtracting one?
ApplyingAs a group, solve \(-5x + 2 \geq -18\) two different ways (e.g. one person isolates the \(x\)-term first, another distributes or reorders differently if possible). Do you land on the same answer? Where could the two paths have gone wrong?
ExtendingDesign a real-world scenario (a budget, a speed limit, a minimum score) whose inequality requires flipping the sign at least once to solve. Trade with another group - can they both write and solve your inequality correctly?
Using Practice Set's Strategy Challenge (Tab 5) as a Group Activity

Each strategy group (No Flip Needed / Flip Required / Distribute, Then Flip) targets a different piece of the skill progression - consider assigning groups deliberately rather than letting every student pick the same one, so you get a genuine spread when you compare answers as a class afterward. A student's progress on whichever group they choose is saved automatically and reviewable in the teacher dashboard's Full Submission Log exactly like any other graded item; the on-screen picker itself doesn't yet remember a prior choice across a reload (a known limitation, not a data-loss issue - nothing a student submits is ever lost, they'd just see the picker screen again).

Scaffolded Support Problems (Flip Rule anchor set)

For a student who is still guessing rather than reasoning through when to flip. Read each hint aloud before they attempt the problem - unlike the graded Practice Set items, the scaffolding is meant to be visible here, not discovered.

ProblemHint to giveAnswer
1. \(-3x < 12\)You're dividing by a negative number. What has to happen to the inequality symbol?\(\mathbf{x > -4}\)
2. \(-x \geq 7\)Multiplying or dividing by \(-1\) still counts - it flips too.\(\mathbf{x \leq -7}\)
3. \(5x > -15\)The coefficient here is positive - no flip. Compare this to #1: what's actually different between them?\(\mathbf{x > -3}\)
4. \(-4x + 3 \leq 19\)Isolate the term with \(x\) first (subtract 3 from both sides) before you divide - the flip only applies to the division step, not the subtraction.\(\mathbf{x \geq -4}\)
Extension / Challenge Problems

Stays within this unit's own scope (one-variable inequalities only - no compound-inequality notation, which belongs to a later lesson per the note on the IXL tab) while pushing past what's graded on any of the six pages.

ProblemAnswer / Notes
1. \(-\dfrac{2}{3}x + 4 < 10\)\(\mathbf{x > -9}\) - a fractional coefficient forces multiplying by a reciprocal (\(-\tfrac{3}{2}\)) rather than simple division, still triggering the flip.
2. Find every whole number \(x\) that makes both \(-2x + 5 \geq -7\) and \(3x - 1 < 20\) true.First inequality: \(x \leq 6\). Second: \(x < 7\). Combined whole numbers: \(0\) through \(6\) (7 values) - the same reasoning behind a compound inequality, built from two separate solves rather than new notation.
3. Write your own solution to a simple inequality that contains exactly one deliberate flip-rule mistake. Trade with a partner and have them find and fix it.Open-ended (generative version of Error Analysis) - constructing a plausible wrong step is a higher-DOK task than just spotting one.
