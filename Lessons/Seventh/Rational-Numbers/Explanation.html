What Is a Rational Number?
A rational number is any number you can write as \(\dfrac{a}{b}\), with \(a,b\) integers and \(b \neq 0\).
The Number System
  • Natural: \(1,2,3,\ldots\)
  • Whole: \(0,1,2,3,\ldots\)
  • Integers: \(\ldots,-1,0,1,\ldots\)
  • Rational: fits \(\frac{a}{b}\) - all integers, all terminating/repeating decimals.
  • Irrational: never terminates, never repeats - \(\pi\), \(\sqrt2\).

Converting Fractions to Decimals
The Rule

Divide numerator ÷ denominator. Denominator's only prime factors 2 and/or 5 → terminates. Anything else → repeats.

Example 1 of 3
Converting Decimals to Fractions
The Rule

Write the digits over the matching place value (tenths → 10, hundredths → 100, thousandths → 1000), then simplify.

Comparing & Ordering Rational Numbers
Convert to the same form (decimals are fastest), then plot on a number line - farther right is greater.

Fraction Operations: A Review
The Rules
  • Add/Subtract: Butterfly Method - cross-multiply for wings, multiply denominators down the middle.
  • Multiply: straight across, then simplify.
  • Divide: Keep-Change-Flip, then multiply.
Example 1 of 4
Decimal Operations: A Review
The Rules
  • Add/Subtract: line up the decimal points.
  • Multiply: multiply as whole numbers, count decimal places.
  • Divide: move both decimal points to make the divisor whole.
