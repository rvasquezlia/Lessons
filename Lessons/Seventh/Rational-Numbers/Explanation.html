What Is a Rational Number?
A rational number is any number you can write as a fraction \(\dfrac{a}{b}\), where \(a\) and \(b\) are integers and \(b \neq 0\). That covers more than fractions that "look like" fractions - every integer, every terminating decimal, and every repeating decimal is rational too, because each one can be rewritten as a ratio of integers.
COPY INTO MATH NOTEBOOK
  • Natural (Counting) Numbers: \(1, 2, 3, \ldots\)
  • Whole Numbers: \(0, 1, 2, 3, \ldots\)
  • Integers: \(\ldots, -2, -1, 0, 1, 2, \ldots\)
  • Rational Numbers: any number that fits \(\dfrac{a}{b}\) - includes all integers, plus every fraction and every terminating or repeating decimal.
  • Irrational Numbers: everything left over - decimals that never terminate and never repeat, like \(\pi\) and \(\sqrt{2}\).

Converting Fractions to Decimals
To write a fraction as a decimal, divide the numerator by the denominator. Some divisions end exactly - a terminating decimal. Others never end and settle into a pattern - a repeating decimal, marked with a bar over the digits that repeat.
COPY INTO NOTEBOOK

Fraction → decimal: divide numerator ÷ denominator. If, in lowest terms, the denominator's only prime factors are 2 and/or 5, the decimal terminates. Any other denominator produces a repeating decimal.

Converting Decimals to Fractions
To write a terminating decimal as a fraction, use place value. The last digit tells you the denominator: tenths → 10, hundredths → 100, thousandths → 1000. Then simplify.
COPY INTO NOTEBOOK

Decimal → fraction: write the digits after the decimal point over the matching place value (10, 100, 1000, ...), then divide numerator and denominator by their greatest common factor. Repeating decimals are rational too, but converting them back to a fraction algebraically is a technique you'll learn in a later course.

Comparing & Ordering Rational Numbers
To compare rational numbers in different forms, convert them all to the same form - decimals are usually the fastest - then plot them on a number line. Just like with integers, whichever value sits farther to the right is greater.

Fraction Operations: A Review
You already learned to add, subtract, multiply, and divide fractions in earlier grades. This is a refresher to sharpen the toolkit you already have, not new instruction.
COPY INTO NOTEBOOK
  • Add / Subtract (Butterfly Method): cross-multiply each numerator by the other fraction's denominator to get the two "wing" values, and multiply the denominators straight down the middle for the new denominator. Add (or subtract) the wing values, in order, for the new numerator. Simplify.
  • Multiply: multiply the numerators together and the denominators together. Simplify (cancel common factors first if it's easier).
  • Divide: keep the first fraction, change the sign to multiplication, and flip the second fraction to its reciprocal - "Keep-Change-Flip." Then multiply as usual.

Decimal Operations: A Review
Same idea as whole-number arithmetic, plus one habit: keep track of the decimal point. This is a refresher of skills from earlier grades.
COPY INTO NOTEBOOK
  • Add / Subtract: line up the decimal points (write in extra zeros if needed), then add or subtract as usual.
  • Multiply: multiply as if both numbers were whole, then count the total decimal places in both factors and place the decimal point that many spots from the right.
  • Divide: if the divisor has a decimal, move its decimal point to make it a whole number, and move the dividend's decimal point the same number of places. Then divide as usual.
