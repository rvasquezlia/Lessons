Set A: Understanding Rational Numbers

2. Which decimal represents an irrational number?

A. \(0.75\)   B. \(0.333\ldots\)   C. \(3.14159265358979\ldots\) (never repeats)   D. \(0.125\)

3. The number line below shows a point between 0 and 1. Which fraction does it represent?

A. \(\dfrac{1}{6}\)   B. \(\dfrac{3}{5}\)   C. \(\dfrac{5}{6}\)   D. \(\dfrac{2}{3}\)
