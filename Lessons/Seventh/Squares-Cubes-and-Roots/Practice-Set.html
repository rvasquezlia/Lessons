Identifying the Base Number
Remember

Missing Value Equations
Remember

A square root (\(\sqrt{x}\)) asks: "What number times itself equals \(x\)?" A cube root (\(\sqrt[3]{x}\)) asks: "What number multiplied by itself three times equals \(x\)?"
