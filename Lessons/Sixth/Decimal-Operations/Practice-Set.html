Decimal Operations: Practice Set

How this page works Every problem on this page is computation only - no word problems (those are on the Word Problems page). Work through the tabs in any order: each one groups problems by type and difficulty so you can practice exactly what you need. Type your own answer first, then click Check - you get up to 2 tries per problem before the correct method is shown. When you finish, type your name above and click Print My Progress.

What to do on this tab For each of the 7 problems: read the work shown, pick "Correct" or "There's a mistake" from the dropdown, type what the correct answer should be, and click Submit My Work. Use the arrows or dots to move between problems. Not every problem actually has an error - read carefully!
